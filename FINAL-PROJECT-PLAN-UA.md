# Що показувати сьогодні
1. Відкрий final-presentation.html — англійські слайди для аудиторії. Стрілки перемикають слайди; 6 слайдів, кожен із явним впливом на рішення SHIP/HOLD.
2. Для себе відкрий presenter-with-evidence.html — ті самі слайди плюс українські пояснення і повні source-файли.
3. Прочитай 06-culture/speaker-notes-uk.md — виступ приблизно 3–4 хвилини.
4. Переглянь 06-culture/questions-and-answers-uk.md — відповіді на очікувані запитання.
5. Для кожного спірного рішення дивись evidence/decision-register.md. Повний пакет даних — ALL-EVIDENCE-UA.md.
6. Для здачі: URL репозиторію + final-presentation.html у Learning Platform. Фінальну здачу не виконано; дедлайн за brief — 7 днів після завершення когорти, дата когорти тут не підтверджена.

## Логіка висновку
Неправильна ціна в row1 → M3 її виявив → M4 Hard bar 0 неправильних цін → 1 failure → HOLD на наданих course evidence. Немає результату виправленої версії, тому не заявляємо ні успішний fix, ні готовність 50 клієнтів.

Документи M1–M6 підготовлені й узгоджені. Це завершені навчальні артефакти з відкритими межами доказів, а не 100% доведена production-надійність. Labels 9/12 потребують adjudication; readiness нового невідомого build не оцінена.
